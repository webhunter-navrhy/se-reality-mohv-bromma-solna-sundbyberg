// Toppmodernt drömhem // Möjlig 4:a // Genomgående planlösning // Rymlig balkong // Exklusivt badrum // Populär Brf med fantastiska gemensamhetsutrymmen // Rofyllt läge med restauranger, caféer samt gym runt husknuten // Garage i huset //

Äntligen saluförs denna fantastiska 3:a (möjlig 4:a) på lugna Trubadurvägen. Känn er som hemma i denna toppmoderna bostad i en oerhört välskött och omtyckt förening. Hemmet karaktäriseras av stora sociala ytor och är perfekt för den som ställer höga krav på standard och komfort. Lägenhetens kök är modernt och ligger i öppen planlösning mot vardagsrummet. I bostaden finns även härlig balkong som nås från rymligt vardagsrum, två bra sovrum samt toppfräscht badrum med tvättmaskin och torktumlare. Slutligen kan erbjudas exemplarisk förvaring i inredd klädkammare. Fantastisk möjlighet att flytta rakt in i ett drömhem med alla önskvärda bekvämligheter för att göra vardagslivet underbart!

Brf Laboratoriet, även kallat "The Lab", är en välskött förening som är mycket omtyckt bland sina medlemmar. Föreningen har garage i huset samt är känd för fantastiska gemensamma utrymmen såsom den gemensamma takterrassen, spaavdelning med jacuzzi samt gemensamhetslokalen. Föreningen har under åren investerat i stora gröna projekt med bl. annat installation av 100 laddplatser i garaget som nås från trapphuset och energisparande åtgärder (besparing på 4,2 miljoner).

Trubadurvägen ligger lugnt beläget i området Ingenting med flertalet restauranger, caféer och gym runt husknuten. Med en kort promenad nås Västra Skogens T-bana med dubbla linjer som tar dig snabbt ner till City och Kungsträdgården. Invid Västra Skogen finns härligt promenadstråk via Pampas Marina ned mot Huvudsta Strand och Jungfrudansens klippor. Längsmed vattnet finns omtyckta badplatser, caféer och restauranger att besöka. Utöver detta nås Kungsholmen på gångavstånd för ytterligare promenadstråk längsmed Kungsholms Strand.
